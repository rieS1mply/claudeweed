# local-photo — домашнее облако

Личное облачное хранилище для фото и файлов на вашем компьютере. Программа:

- создаёт папку `Хранилище` и раскладывает всё по датам **создания** (дата съёмки из EXIF для фото, из метаданных для видео, дата изменения для обычных файлов):
  ```
  Хранилище/
    Фото/2024/03-Март/IMG_0001.jpg
    Файлы/2024/03-Март/Договор.pdf
  ```
- сама скачивает `cloudflared` и открывает бесплатный туннель Cloudflare — сайт становится доступен по адресу вида `https://случайные-слова.trycloudflare.com`;
- присылает этот адрес в Telegram при каждом запуске (адрес меняется при перезапуске);
- пускает на сайт только по логину и паролю.

Что умеет сайт:

- **Фото** — галерея по месяцам, просмотр со свайпами, редактор: обрезка с пропорциями, поворот, отражение, яркость, контраст, насыщенность, теплота. Сохранить можно поверх оригинала (он уходит в корзину) или копией; дата съёмки сохраняется.
- **Файлы** — переименование, встроенный редактор текстовых файлов (txt, md, csv, json, код, конфиги).
- **Конвертация** — фото в JPG/PNG/WebP, CSV ⇄ JSON, TXT ⇄ MD. Результат кладётся копией рядом с оригиналом. HEIC → JPG должно работать в Safari (он умеет открывать HEIC), но на iPhone это ещё не проверялось; Chrome HEIC не открывает. DOCX → PDF и подобное не поддерживается.
- На iPhone браузер не может обработать фото больше ~16 Мп целиком: такие фото после редактирования сохраняются только уменьшенной копией, оригинал не перезаписывается.
- **Заметки** — хранятся в `Хранилище/Заметки/*.md`, доступны с любого устройства, сохраняются сами; при одновременной правке с двух устройств сайт предупредит.
- **Выбор нескольких** — кнопка «Выбрать» или долгое нажатие; касание отмечает, проведение пальцем отмечает диапазон. Выбранное можно сохранить в галерею телефона (меню «Поделиться»), скачать одним ZIP или удалить.
- **Сортировка** — по дате съёмки/создания или по дате загрузки (выбор запоминается).
- **Telegram** — фото, видео и файлы, отправленные боту, сохраняются в облако; `/url` присылает адрес.
- **Терминал** (выключен, пока его не включат на самом компьютере) — командная строка этого компьютера с ноутбука или телефона. Один общий сеанс: начали на ноутбуке — продолжили на телефоне; при обрыве связи (метро, смена Wi-Fi) программы продолжают работать, а после переподключения экран возвращается как был. Вывод сжимается (обычно в 3–7 раз), на телефоне есть ряд клавиш Esc, Tab, Ctrl, стрелки. О каждом входе в терминал приходит сообщение в Telegram (не чаще раза в час на адрес). Оболочка: zsh/bash пользователя на macOS/Linux, PowerShell на Windows.
- **Корзина** — всё удалённое хранится 30 дней (`.local-photo/trash`), потом удаляется навсегда; можно восстановить или отменить удаление сразу.

## Сборка

Нужен Rust (https://rustup.rs).

```sh
cargo build --release          # для текущей системы → target/release/local-photo
```

Версия для Windows с Mac/Linux (кросс-компиляция через Zig, без Windows SDK):

```sh
rustup target add x86_64-pc-windows-gnu
python3 -m pip install --user ziglang
cargo install cargo-zigbuild --locked
cargo zigbuild --release --target x86_64-pc-windows-gnu
# → target/x86_64-pc-windows-gnu/release/local-photo.exe
```

Linux тем же способом, статически (musl) — работает на любом дистрибутиве:

```sh
rustup target add x86_64-unknown-linux-musl aarch64-unknown-linux-musl armv7-unknown-linux-musleabihf
cargo zigbuild --release --target x86_64-unknown-linux-musl          # ПК/сервер
cargo zigbuild --release --target aarch64-unknown-linux-musl         # Raspberry Pi 4/5 (64 бит), ARM
cargo zigbuild --release --target armv7-unknown-linux-musleabihf     # Raspberry Pi (32 бит)
```

Готовая программа — один файл, интерфейс сайта встроен в него. Нужны только системные библиотеки Windows 10/11.

## Запуск

Программу можно положить куда угодно — рядом с ней ничего не создаётся. При первом запуске она спросит:

1. **где хранить фото и файлы** — любая папка, в том числе на другом или внешнем диске (можно перетащить папку в окно терминала; Enter — `~/Облако`);
2. логин и пароль для сайта (пароль хранится только в виде хэша Argon2);
3. токен Telegram-бота — создайте бота у @BotFather (`/newbot`), вставьте токен и отправьте боту `/start`. Можно пропустить, адрес всё равно печатается в консоли;
4. **включить ли терминал** на сайте (по умолчанию нет);
5. **включить ли автозапуск** — тогда облако уходит в фон (окно можно закрыть) и само запускается при входе в систему: Windows — автозагрузка, macOS — LaunchAgent, Linux — пользовательская служба systemd.

После запуска показывается адрес и QR-код для камеры телефона. Повторный запуск, когда облако уже работает, не создаёт вторую копию, а показывает текущий адрес. Вход на сайт сохраняется на 30 дней и переживает перезапуск (на диске — только хэши сессий).

### Где что лежит

```
Файл настроек (config.json: storage_dir, логин, хэш пароля, Telegram), журнал local-photo.log,
status.json работающего облака, sessions.json и cloudflared:
  Windows:  %APPDATA%\local-photo\
  macOS:    ~/Library/Application Support/local-photo/
  Linux:    ~/.config/local-photo/

Выбранная папка хранилища:
  Фото/2024/03-Март/...      Файлы/...      Заметки/*.md
  .local-photo/              корзина, превью, временные загрузки (тот же диск, что и фото)
```

Сменить папку: запустите с `--setup` — программа предложит перенести уже накопленные файлы. Или поправьте `storage_dir` в `config.json` вручную (файлы тогда перенесите сами).

Если папка хранилища недоступна (например, не подключён внешний диск), программа не запустится и скажет об этом — пустое хранилище в другом месте она не создаёт.

Старая раскладка (всё рядом с программой) переносится автоматически при первом запуске новой версии.

Параметры:

| Флаг | Что делает |
|---|---|
| `--status` | работает ли облако, адрес и QR-код |
| `--stop` | остановить облако, работающее в фоне |
| `--autostart on` / `off` | включить / выключить автозапуск в фоне |
| `--terminal on` / `off` | разрешить / запретить терминал на сайте (работающее облако подхватит сразу, без перезапуска) |
| `--setup` | заново выбрать папку хранилища, логин, пароль и Telegram |
| `--port <порт>` | локальный порт (по умолчанию 8787) |
| `--no-tunnel` | без доступа из интернета, только `http://127.0.0.1:8787` |
| `--dir <папка>` | держать настройки в этой папке (переносная/тестовая установка) |

## Безопасность

- Сервер слушает только `127.0.0.1` — из локальной сети напрямую к нему не подключиться, только через туннель (HTTPS).
- После 5 неверных паролей адрес блокируется (30 с, затем вдвое дольше, до часа); при массовом подборе вход закрывается для всех на 15 минут.
- Сессия — случайный 256-битный токен в cookie `HttpOnly; Secure; SameSite=Strict`, живёт 30 дней или до перезапуска программы.
- Все запросы к файлам требуют входа; изменяющие запросы защищены от CSRF.
- Терминал выключен по умолчанию; включить его можно только на самом компьютере (`--setup` или `--terminal on`). Кто знает пароль — управляет компьютером, поэтому пароль должен быть надёжным. Подключение к терминалу принимается только со страницы самого облака (проверка Origin), сеанс закрывается при выходе из аккаунта или выключении терминала.
- Имена файлов очищаются, выйти за пределы хранилища через путь нельзя; файлы с одинаковыми именами не перезаписываются (`IMG (2).jpg`).

## Ограничения первой версии

- Превью для HEIC/RAW не строятся (показывается значок), сами файлы хранятся и скачиваются как есть. HEIC открывается в Safari.
- У видео нет превью-кадра, но оно воспроизводится в браузере (MP4; MOV — в Safari и обычно в Chrome на Mac).
- Бесплатный туннель Cloudflare не даёт гарантий доступности и меняет адрес при каждом перезапуске.
- Терминал на Windows (PowerShell через ConPTY) собирается, но ещё не проверялся на живой системе. Старые браузеры без `DecompressionStream` (Safari до 16.4) получают вывод без сжатия.

## Структура кода

| Файл | Что внутри |
|---|---|
| `src/main.rs` | запуск, параметры, сервер + туннель, остановка по Ctrl+C |
| `src/config.rs` | папки, `config.json`, первая настройка |
| `src/web.rs` | HTTP API: вход, список, файлы, превью, загрузка по частям |
| `src/auth.rs` | сессии и защита от подбора пароля |
| `src/storage.rs` | разделы, даты из EXIF/MP4, безопасные имена и пути |
| `src/thumbs.rs` | превью с учётом поворота фото |
| `src/notes.rs` | заметки (Markdown-файлы) |
| `src/trash.rs` | корзина на 30 дней |
| `src/tunnel.rs` | скачивание и перезапуск cloudflared |
| `src/telegram.rs` | отправка адреса в Telegram |
| `static/app.js` | ядро интерфейса: разделы, галерея, просмотр, загрузка, анимации |
| `static/editor.js` | редактор фото, конвертация, текстовый редактор |
| `static/notes.js`, `static/trash.js` | заметки и корзина |
| `static/select.js` | выбор нескольких фото/файлов и действия с ними |
| `src/terminal.rs` | терминал: оболочка в PTY, история для переподключения, сжатие вывода |
| `static/terminal.*` | страница терминала; `static/xterm*` — xterm.js 6.0.0 и addon-fit 0.11.0 (MIT) |
| `src/zips.rs` | сборка ZIP для скачивания выбранного |
| `src/bot.rs` | Telegram-бот: приём файлов из чата |
| `static/` | откройте `static/index.html` прямо в браузере — будет демо-режим |
