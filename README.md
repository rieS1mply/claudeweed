# local-photo — домашнее облако

Личное облачное хранилище для фото и файлов на вашем компьютере. Программа:

- создаёт папку `Хранилище` и раскладывает всё по датам **создания** (дата съёмки из EXIF для фото, из метаданных для видео, дата изменения для обычных файлов):
  ```
  Хранилище/
    Фото/2024/03-Март/IMG_0001.jpg
    Файлы/2024/03-Март/Договор.pdf
  ```
- сама скачивает `cloudflared` и открывает бесплатный туннель Cloudflare — сайт становится доступен по адресу вида `https://случайные-слова.trycloudflare.com`;
- присылает этот адрес в Telegram при каждом запуске (адрес меняется при перезапуске);
- пускает на сайт только по логину и паролю.

Что умеет сайт:

- **Фото** — галерея по месяцам, просмотр со свайпами, редактор: обрезка с пропорциями, поворот, отражение, яркость, контраст, насыщенность, теплота. Сохранить можно поверх оригинала (он уходит в корзину) или копией; дата съёмки сохраняется.
- **Файлы** — переименование, встроенный редактор текстовых файлов (txt, md, csv, json, код, конфиги).
- **Конвертация** — фото в JPG/PNG/WebP, CSV ⇄ JSON, TXT ⇄ MD. Результат кладётся копией рядом с оригиналом. HEIC → JPG должно работать в Safari (он умеет открывать HEIC), но на iPhone это ещё не проверялось; Chrome HEIC не открывает. DOCX → PDF и подобное не поддерживается.
- На iPhone браузер не может обработать фото больше ~16 Мп целиком: такие фото после редактирования сохраняются только уменьшенной копией, оригинал не перезаписывается.
- **Заметки** — хранятся в `Хранилище/Заметки/*.md`, доступны с любого устройства, сохраняются сами; при одновременной правке с двух устройств сайт предупредит.
- **Выбор нескольких** — кнопка «Выбрать» или долгое нажатие; касание отмечает, проведение пальцем отмечает диапазон. Выбранное можно сохранить в галерею телефона (меню «Поделиться»), скачать одним ZIP или удалить.
- **Сортировка** — по дате съёмки/создания или по дате загрузки (выбор запоминается).
- **Telegram** — фото, видео и файлы, отправленные боту, сохраняются в облако; `/url` присылает адрес.
- **Терминал** (выключен, пока его не включат на самом компьютере) — командная строка этого компьютера с ноутбука или телефона. Один общий сеанс: начали на ноутбуке — продолжили на телефоне; при обрыве связи (метро, смена Wi-Fi) программы продолжают работать, а после переподключения экран возвращается как был. Вывод сжимается (обычно в 3–7 раз), на телефоне есть ряд клавиш Esc, Tab, Ctrl, стрелки. О каждом входе в терминал приходит сообщение в Telegram (не чаще раза в час на адрес). Оболочка: zsh/bash пользователя на macOS/Linux, PowerShell на Windows.
- **Корзина** — всё удалённое хранится 30 дней (`.local-photo/trash`), потом удаляется навсегда; можно восстановить или отменить удаление сразу.
- **Свои папки и альбомы.** В «Файлах» — настоящие папки, как в файловом менеджере: строки-папки вверху списка, нажатие открывает папку, над списком путь «Файлы › Работа › Отчёты» (нажатие на часть пути — туда). Папки могут быть вложенными; «+» рядом с путём создаёт папку внутри открытой, а пока папка открыта, загрузка идёт прямо в неё. Поиск ищет по всему, что лежит ниже открытой папки. В «Фото» альбомы — ряд кнопок над сеткой. Файл или выбранное перекладывается через «⋯ → Переложить в папку»; «Убрать из папки» возвращает в раскладку по датам. «⋯» у папки (или нажатие на открытую) — переименовать или удалить (только пустую).
- **Ссылки без пароля** — «⋯ → Ссылка без пароля» (или «Ссылка» при выборе нескольких): ссылка на 1, 7 или 30 дней копируется в буфер. Получатель видит только эти файлы: фото и видео смотрит, остальное скачивает. Все ссылки и отзыв — кнопка со скрепкой вверху.
- **Просмотр** PDF (встроенный просмотрщик браузера, в новой вкладке), аудио (плеер внизу экрана, можно листать дальше) и Markdown (оформленный текст, «Править» открывает редактор).
- **Поиск** по имени, а в «Файлах» и «Заметках» — ещё и по тексту внутри (заметки и текстовые файлы до 2 МБ); под найденным файлом показан кусок текста с совпадением.
- **HEIC с iPhone** — сервер HEIC не декодирует, а Safari умеет: когда галерею открывают на iPhone/в Safari (или загружают HEIC оттуда), браузер делает JPEG-превью и отправляет его в облако. После этого миниатюры и просмотр работают везде, в том числе в Chrome на компьютере.
- **Язык** — русский или английский (кнопка с глобусом, по умолчанию — язык браузера). Сообщения в Telegram и консоль: `local-photo --lang en` / `--lang ru`.

## Сборка

Пошаговая установка для агента Claude (или человека) на macOS, Linux и Windows — [INSTALL.md](INSTALL.md).

Нужен Rust (https://rustup.rs).

Для разработки — тестовая установка рядом с исходниками, без туннеля и не трогая настоящее облако (подробнее в [CLAUDE.md](CLAUDE.md)):

```sh
cargo run --release --example dev_setup                      # создаёт .dev/ (логин dev, пароль devpassword)
cargo run --release -- --dir .dev --no-tunnel --port 8788     # http://127.0.0.1:8788
```

```sh
cargo build --release          # для текущей системы → target/release/local-photo
```

Версия для Windows с Mac/Linux (кросс-компиляция через Zig, без Windows SDK):

```sh
rustup target add x86_64-pc-windows-gnu
python3 -m pip install --user ziglang
cargo install cargo-zigbuild --locked
cargo zigbuild --release --target x86_64-pc-windows-gnu
# → target/x86_64-pc-windows-gnu/release/local-photo.exe
```

Linux тем же способом, статически (musl) — работает на любом дистрибутиве:

```sh
rustup target add x86_64-unknown-linux-musl aarch64-unknown-linux-musl armv7-unknown-linux-musleabihf
cargo zigbuild --release --target x86_64-unknown-linux-musl          # ПК/сервер
cargo zigbuild --release --target aarch64-unknown-linux-musl         # Raspberry Pi 4/5 (64 бит), ARM
cargo zigbuild --release --target armv7-unknown-linux-musleabihf     # Raspberry Pi (32 бит)
```

Готовая программа — один файл, интерфейс сайта встроен в него. Нужны только системные библиотеки Windows 10/11.

## Запуск

Программу можно положить куда угодно — рядом с ней ничего не создаётся. При первом запуске она спросит:

1. **где хранить фото и файлы** — любая папка, в том числе на другом или внешнем диске (можно перетащить папку в окно терминала; Enter — `~/Облако`);
2. логин и пароль для сайта (пароль хранится только в виде хэша Argon2);
3. токен Telegram-бота — создайте бота у @BotFather (`/newbot`), вставьте токен и отправьте боту `/start`. Можно пропустить, адрес всё равно печатается в консоли;
4. **включить ли терминал** на сайте (по умолчанию нет);
5. **включить ли автозапуск** — тогда облако уходит в фон (окно можно закрыть) и само запускается при входе в систему: Windows — автозагрузка, macOS — LaunchAgent, Linux — пользовательская служба systemd.

После запуска показывается адрес и QR-код для камеры телефона. Повторный запуск, когда облако уже работает, не создаёт вторую копию, а показывает текущий адрес. Вход на сайт сохраняется на 30 дней и переживает перезапуск (на диске — только хэши сессий).

### Где что лежит

```
Файл настроек (config.json: storage_dir, логин, хэш пароля, Telegram), журнал local-photo.log,
status.json работающего облака, sessions.json и cloudflared:
  Windows:  %APPDATA%\local-photo\
  macOS:    ~/Library/Application Support/local-photo/
  Linux:    ~/.config/local-photo/

Выбранная папка хранилища:
  Фото/2024/03-Март/...      Файлы/...      Заметки/*.md
  .local-photo/              корзина, превью, временные загрузки (тот же диск, что и фото)
```

Сменить папку: запустите с `--setup` — программа предложит перенести уже накопленные файлы. Или поправьте `storage_dir` в `config.json` вручную (файлы тогда перенесите сами).

Если папка хранилища недоступна (например, не подключён внешний диск), программа не запустится и скажет об этом — пустое хранилище в другом месте она не создаёт.

Старая раскладка (всё рядом с программой) переносится автоматически при первом запуске новой версии.

Параметры:

| Флаг | Что делает |
|---|---|
| `--status` | работает ли облако, адрес и QR-код |
| `--stop` | остановить облако, работающее в фоне |
| `--autostart on` / `off` | включить / выключить автозапуск в фоне |
| `--terminal on` / `off` | разрешить / запретить терминал на сайте (работающее облако подхватит сразу, без перезапуска) |
| `--runner on` / `off` | разрешить / запретить запуск кода на сайте (см. «Запуск кода») |
| `--agent on` / `off` | разговор с Claude Code этого компьютера через Telegram-бота (см. «Claude в Telegram») |
| `--2fa on` / `off` | вход с кодом из приложения-аутентификатора (см. ниже) |
| `--backup <папка>` / `off` | ежедневная резервная копия хранилища в эту папку (см. ниже) |
| `--backup-now` | сделать резервную копию сейчас |
| `--tunnel named` / `quick` | постоянный адрес на своём домене / снова случайный trycloudflare.com |
| `--setup` | заново выбрать папку хранилища, логин, пароль и Telegram |
| `--new-login` | новые случайные логин и пароль — приходят только в Telegram (в консоль и журнал не пишутся), все устройства выходят; облако сначала остановить (`--stop`) |
| `--port <порт>` | локальный порт (по умолчанию 8787) |
| `--no-tunnel` | без доступа из интернета, только `http://127.0.0.1:8787` |
| `--dir <папка>` | держать настройки в этой папке (переносная/тестовая установка) |

### Резервная копия

```
local-photo --backup E:\Копии        # папка на другом (лучше внешнем) диске
local-photo --backup-now             # первая копия сразу, не дожидаясь расписания
```

Раз в сутки (первый раз — через 3 минуты после запуска) облако копирует новые и изменённые
файлы в `E:\Копии\Облако (резервная копия)`. Из копии ничего не удаляется: файл, удалённый
в облаке, там остаётся. Миниатюры, корзина и недокачанные загрузки не копируются. Если диск
отключён, облако пробует каждый час и раз в сутки пишет об этом в Telegram. Состояние —
в `local-photo --status`.

### Вход с кодом из приложения

`local-photo --2fa on` показывает QR-код: отсканируйте его в Google Authenticator, Microsoft
Authenticator, 2FAS, Aegis или любом другом приложении с одноразовыми кодами и введите код.
После этого вход на сайт — логин, пароль и 6-значный код. Неверные коды считаются как неверные
пароли (блокировка подбора), один и тот же код дважды не принимается. Работающее облако
подхватывает включение сразу. Потеряли телефон — `local-photo --2fa off` на компьютере.

### Устройства, журнал входов и вход через Telegram

- **Устройства и входы** (значок щита в шапке, на телефоне — в «⋯»): какие устройства вошли, с
  какого адреса и когда были активны; завершить любой сеанс или «Выйти на всех других»; журнал
  последних попыток входа (удачных и нет).
- После каждого входа по паролю бот присылает сообщение: устройство и адрес, кнопки «Завершить
  этот сеанс» и «Выйти везде». После нескольких неверных паролей подряд — предупреждение
  (не чаще раза в час на адрес).
- **Войти через Telegram** на странице входа (если подключён бот и не включены коды из
  приложения): бот присылает запрос с кодом, тот же код виден на странице; «Войти» в Telegram —
  и страница входит без пароля. Запрос живёт 3 минуты, не больше 3 одновременно и 10 в час.
- Вход по Face ID (passkey) пока не сделан: браузеры привязывают ключ к адресу сайта, а адрес
  trycloudflare меняется при каждом перезапуске. С постоянным адресом (`--tunnel named`/`funnel`)
  его можно добавить.

### Поиск фото по содержимому

`local-photo --ai on` — локальная модель в [Ollama](https://ollama.com) (по умолчанию
`qwen2.5vl:7b`, скачать: `ollama pull qwen2.5vl:7b`, ~6 ГБ) в фоне описывает каждое фото:
короткое описание и ключевые слова по-русски и по-английски. Поиск в «Фото» находит по ним:
«собака», «костёр», «чек», «beach». Ничего не уходит с компьютера. Около 2 с на фото с
видеокартой; новые фото описываются в течение минуты, изменённые — заново. HEIC — после того,
как браузер сделал превью. Если Ollama установлена, но не запущена, облако запускает
`ollama serve` само. Другая модель — `"vision_model"` в `config.json`.

### Запуск кода (как онлайн-компилятор)

`local-photo --runner on` — в редакторе кода появляется зелёная кнопка **▶ Запустить**
(Ctrl+Enter), а в шапке сайта — **</>** «Новый код»: выбрать язык, получить готовую программу,
изменить, запустить и, если нужно, сохранить в «Файлы».

- Языки — те, что установлены на компьютере: Python, JavaScript и TypeScript (Node.js), C и C++
  (gcc/clang), C# (.NET 10), Java (11+), Go, Rust, PHP, Ruby, Lua, PowerShell, Bash. Чего нет —
  показано серым с подсказкой, что поставить; после установки — «Обновить список» (на Windows
  облако читает PATH из реестра, перезапуск не нужен). Bash на Windows — из Git for Windows.
  Всё разом на Windows: `winget install OpenJS.NodeJS.LTS BrechtSanders.WinLibs.POSIX.UCRT
  Microsoft.DotNet.SDK.10 GoLang.Go PHP.PHP.8.4 RubyInstallerTeam.Ruby.3.4 DEVCOM.Lua`.
- Вывод появляется по мере печати, ошибки — красным; поле **Ввод** — то, что программа прочитает
  со стандартного ввода. **Стоп** останавливает программу и всё, что она запустила.
- Ограничения: компиляция до 60 с, работа до 15 с, вывод до 1 МБ, не больше двух запусков сразу.
  Каждый запуск — во временной папке, которая потом удаляется.
- На телефоне над клавиатурой — строка символов `{ } ( ) [ ] ; = " < >` и Tab, вывод
  разворачивается на весь экран нажатием на его заголовок; на компьютере границу между кодом и
  выводом можно тянуть мышью.

Это выполнение кода на компьютере с правами пользователя, как терминал: кто знает пароль, может
запустить что угодно. Поэтому включается только на самом компьютере; советуем вместе с `--2fa on`.

### Компьютер (все папки, как Finder)

`local-photo --files on` — в шапке сайта появляется кнопка с монитором: все диски и папки этого
компьютера, как Finder на Mac (на телефоне — как приложение «Файлы» на iPhone). Выключить:
`--files off` (срабатывает сразу, без перезапуска).

- Слева — «Избранное» (Рабочий стол, Документы, Загрузки…), диски со свободным местом и папки
  облака. Сверху — назад/вперёд, путь, поиск по имени во всех вложенных папках.
- Четыре вида: **значки** (с миниатюрами фото), **список** (сортировка по столбцам, папки
  раскрываются треугольником), **колонки**, **галерея**. Справа — панель просмотра и свойства.
- **Пробел** — быстрый просмотр: фото, видео, музыка, PDF, Markdown, любой текст и код; текст
  можно сразу исправить и сохранить (Ctrl+S). Стрелки — соседние файлы.
- Выделение кликом, Shift/Ctrl, рамкой мышью, Ctrl+A. Перетаскивание на папку, в боковую
  панель или на путь — перемещение (с Alt/Ctrl или на другой диск — копирование); файлы с
  рабочего стола браузера — загрузка в эту папку (большие — частями, с продолжением).
- Правый клик / долгое нажатие: открыть, скачать (папки и несколько файлов — ZIP),
  переименовать, дублировать, копировать / вырезать / вставить, свойства (размер папки),
  скопировать путь, **в Корзину** (Корзина Windows — можно восстановить) или удалить сразу.
- Клавиши как в Finder: Enter — переименовать, Ctrl+↓ или двойной клик — открыть, Ctrl+↑ —
  наверх, Delete или Ctrl+Backspace — в Корзину, Shift+Delete — сразу, Ctrl+C/X/V/D,
  Ctrl+Shift+N — новая папка, Ctrl+1…4 — вид, Ctrl+Shift+. — скрытые файлы, Ctrl+Shift+G —
  перейти к папке, Ctrl+I — свойства, Alt+←/→ — назад/вперёд, набор букв — переход к имени.
- Копирование, перемещение и удаление идут в фоне с прогрессом и кнопкой отмены; ничего не
  перезаписывается — совпадающее имя получает « (2)».

Кто знает пароль, может читать, менять и удалять любые файлы пользователя. Поэтому включается
только на самом компьютере, о каждом входе в раздел приходит сообщение в Telegram (раз в час с
одного адреса), каждое изменение пишется в журнал. Всегда закрыты папка настроек облака (пароль,
токены) и служебная папка хранилища; системные папки Windows (Windows, Program Files) — только
просмотр. Советуем вместе с `--2fa on`.

### Claude в Telegram

Нужны подключённый Telegram-бот (`--setup`) и Claude Code на компьютере, в который один раз
вошли (`claude`, затем `/login`). Включение: `local-photo --agent on`.

- Обычный текст боту — сообщение Claude. Пока он работает, под вашим сообщением обновляется
  строка с шагами («📄 Читаю main.rs», «💻 cargo test»), потом приходит ответ.
- Разговор один и продолжается от сообщения к сообщению, в том числе после перезапуска
  облака. **/new** — начать новый, **/stop** — прервать, **/dir D:\Проекты** — сменить папку,
  в которой он работает (по умолчанию — папка пользователя), **/status** — что сейчас с ним.
- Сообщения, отправленные, пока он занят, ждут очереди. Файл с подписью сохраняется в облако,
  а подпись уходит Claude вместе с путём к файлу («что на этом фото?»).
- Пока компьютер спит или выключен, Claude не отвечает; сообщения Telegram хранит до суток.

Claude работает на компьютере с правами пользователя: читает и меняет файлы, запускает команды.
Опасные действия он не выполняет сам (режим `auto` Claude Code), но доступ к вашему Telegram
означает доступ к компьютеру — включите облачный пароль Telegram. Бот отвечает только вашему
чату; текст разговора в журнал облака не пишется.

### Автозагрузка с iPhone

Новые фото с iPhone могут сами уходить в облако через приложение «Быстрые команды» (Shortcuts).

1. На компьютере: `local-photo --upload-token new` — программа покажет **ключ** (один раз; новый ключ
   отменяет старый, `--upload-token off` выключает автозагрузку).
2. Нужен постоянный адрес (`--tunnel funnel` или `--tunnel named`, см. ниже): адрес trycloudflare меняется при каждом
   перезапуске, и его пришлось бы каждый раз исправлять в команде.
3. iPhone → «Быстрые команды» → «Автоматизация» → «+» → например «Время суток» (каждый день в 3:00)
   или «Зарядное устройство подключено» → «Запускать сразу».
4. Действия команды:
   - **Найти фото**: «Дата добавления» — «за последние 2 дня» (фильтр можно настроить; повторно
     присланные файлы облако пропускает, так что пересечение дней не создаёт копий);
   - **Повторить с каждым** объектом из «Фото»; внутри:
     - **Получить содержимое URL**: адрес `https://ваш-адрес/api/auto-upload?name=` + переменная
       «Повторить объект» → «Имя» (с расширением, например `IMG_1234.HEIC`); метод **POST**;
       заголовок `Authorization` = `Bearer <ключ>`; тело запроса — **Файл**, «Повторить объект».
5. Запустите команду вручную один раз и разрешите доступ к фото.

Файл раскладывается как обычная загрузка (по дате съёмки). Ответ сервера: `{"duplicate": true}`,
если такой файл (то же имя и размер в том же месяце) уже есть. Один файл — до 100 МБ (ограничение
Cloudflare). Неверный ключ считается как неверный пароль (блокировка подбора).

### Постоянный адрес

Случайный адрес trycloudflare.com меняется при каждом перезапуске. Постоянный адрес — два способа.

**Tailscale Funnel (бесплатно, без своего домена)** — адрес вида `https://компьютер.tailXXXX.ts.net`:

1. Установите Tailscale (`winget install Tailscale.Tailscale` или https://tailscale.com/download)
   и войдите в аккаунт (значок Tailscale у часов → Log in; бесплатный план).
2. На компьютере: `local-photo --tunnel funnel`. Если Tailscale попросит разрешить Funnel или
   HTTPS-сертификаты, программа покажет ссылку — откройте её, нажмите «Enable» и повторите команду.
3. Перезапустите облако: `local-photo --stop`, затем `local-photo --autostart on`.

Трафик идёт через серверы Tailscale (шифруется до этого компьютера); облако каждые 10 минут
проверяет, что публикация включена. Вернуться к случайному адресу: `local-photo --tunnel quick`
(публикация в Tailscale выключается). Имя компьютера в адресе можно поменять в админке Tailscale
(Machines → … → Edit machine name).

**Свой домен (Cloudflare)** — именованный туннель Cloudflare; нужен **свой домен**, добавленный
в Cloudflare (бесплатного тарифа хватает; сам домен покупается у любого регистратора).

1. https://one.dash.cloudflare.com → Networks → Tunnels → **Create a tunnel** → Cloudflared, любое имя.
2. На шаге установки скопируйте команду с токеном (длинная строка, начинается с `eyJ`).
   Сам cloudflared ставить не нужно — облако запускает свой.
3. **Public Hostname**: поддомен и домен (например `cloud.example.com`), Service — `HTTP`,
   URL — `localhost:8787`.
4. На компьютере: `local-photo --tunnel named` — введите адрес и вставьте токен (можно всю команду).
5. Перезапустите облако: `local-photo --stop`, затем `local-photo --autostart on`.

Токен хранится в `config.json` рядом с паролем и передаётся cloudflared через переменную среды
(не виден в списке процессов). Вернуть случайный адрес: `local-photo --tunnel quick`.

## Безопасность

- Сервер слушает только `127.0.0.1` — из локальной сети напрямую к нему не подключиться, только через туннель (HTTPS).
- После 5 неверных паролей адрес блокируется (30 с, затем вдвое дольше, до часа); при массовом подборе вход закрывается для всех на 15 минут.
- По желанию — второй фактор: код из приложения-аутентификатора (`--2fa on`, TOTP RFC 6238).
- Вход через Telegram подтверждает только чат владельца; запрос опознаётся по 128-битному ключу, известному лишь странице, которая его создала; при включённых кодах из приложения этот вход недоступен (он бы их обходил). Список устройств хранит только SHA-256 токенов.
- Сессия — случайный 256-битный токен в cookie `HttpOnly; Secure; SameSite=Strict`, живёт 30 дней или до перезапуска программы.
- Все запросы к файлам требуют входа; изменяющие запросы защищены от CSRF.
- Терминал выключен по умолчанию; включить его можно только на самом компьютере (`--setup` или `--terminal on`). Кто знает пароль — управляет компьютером, поэтому пароль должен быть надёжным. Подключение к терминалу принимается только со страницы самого облака (проверка Origin), сеанс закрывается при выходе из аккаунта или выключении терминала.
- Claude в Telegram выключен по умолчанию и включается только на самом компьютере (`--agent on`); бот слушает только чат владельца, выбранный при настройке.
- «Компьютер» выключен по умолчанию (`--files on` — только на самом компьютере). Путь от страницы принимается только абсолютный и из обычных имён (без `..`, `\\?\`, сетевых путей, потоков `файл:поток`, имён устройств вроде `NUL`); ссылки раскрываются, и проверяется уже настоящее место. Настройки облака закрыты полностью, системные папки Windows — только чтение; удаление — в Корзину Windows. Файлы с диска, кроме фото, видео, музыки и PDF, отдаются только на скачивание (`attachment` + `CSP sandbox`).
- Имена файлов очищаются, выйти за пределы хранилища через путь нельзя; файлы с одинаковыми именами не перезаписываются (`IMG (2).jpg`).
- Ссылка без пароля — 128-битный случайный ключ в адресе (`/s/<ключ>`); открывает только названные файлы и только до срока; список ссылок — `shares.json` в папке настроек. Отозванная или истёкшая ссылка сразу перестаёт работать.
- Автозагрузка (`/api/auto-upload`) принимает только файлы с ключом `--upload-token`; хранится лишь SHA-256 ключа. Без ключа в настройке адрес не существует (404).
- Markdown показывается без HTML: теги из файла — просто текст, ссылки работают только `http(s)`/`mailto`, картинки по внешним адресам не загружаются. PDF отдаётся строго как `application/pdf` (с `nosniff`), поэтому открыться как страница сайта не может.

## Ограничения первой версии

- Превью HEIC делает браузер, который умеет HEIC (Safari): пока галерею не открывали на iPhone/в Safari, в Chrome у HEIC значок вместо миниатюры. RAW (DNG, CR2…) превью не получают.
- У видео нет превью-кадра, но оно воспроизводится в браузере (MP4; MOV — в Safari и обычно в Chrome на Mac).
- Бесплатный туннель Cloudflare не даёт гарантий доступности и меняет адрес при каждом перезапуске (постоянный адрес — `--tunnel funnel` через Tailscale или `--tunnel named` со своим доменом).
- Старые браузеры без `DecompressionStream` (Safari до 16.4) получают вывод терминала без сжатия.
