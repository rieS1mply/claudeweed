## Экскурс по проекту

**Что это.** Личное домашнее облако для фото и файлов. Работает на компьютере владельца,
наружу открывается бесплатным туннелем Cloudflare (`https://…trycloudflare.com`), адрес
приходит в Telegram при каждом запуске. Вход по логину и паролю.

**Из чего сделано.** Сервер на Rust (axum + tokio), интерфейс на чистом JS без сборщика.
Всё собирается в один `.exe` (~9 МБ), сайт встроен в бинарник через `rust-embed`.

**Как устроено:**

| Часть | Где | Что делает |
|---|---|---|
| Сервер | `src/main.rs`, `src/web.rs` | слушает только `127.0.0.1:8787`, все HTTP-маршруты, CSRF, загрузка по частям |
| Вход | `src/auth.rs` | сессии (на диске только хэши), блокировка подбора пароля |
| Хранилище | `src/storage.rs` | раскладка `Фото/2026/10-Октябрь/…`, даты из EXIF/MP4, защита путей |
| Туннель | `src/tunnel.rs` | скачивает и перезапускает cloudflared |
| Telegram | `src/telegram.rs`, `src/bot.rs` | присылает адрес, принимает файлы из чата |
| Терминал | `src/terminal.rs`, `static/terminal.*` | до 8 сеансов-вкладок, окно делится на 1/2/4 панели (PowerShell/ConPTY на Windows), xterm.js |
| Запуск кода | `src/runner.rs`, `static/runner.js` | как онлайн-компилятор: 14 языков из установленных на компьютере, вывод по ходу, песочница «</>» |
| Остальное | `src/trash.rs`, `notes.rs`, `zips.rs`, `thumbs.rs` | корзина 30 дней, заметки, ZIP, превью |
| Интерфейс | `static/app.js` + `editor.js`, `notes.js`, `trash.js`, `select.js` | галерея, поиск, редактор фото, редактор кода с подсветкой (`highlight.js`), заметки, корзина, выбор нескольких |
| Автозапуск | `src/service.rs` | Windows Run / launchd / systemd, `--stop`, `--status` |

**На этом компьютере:**

- Исходники (рабочая копия, git → `github.com/rieS1mply/claudeweed`): `C:\Users\admin\Documents\claudeweed-main`.
  Старый клон в `C:\Users\admin\Documents\cloud\claudeweed` — не основной.
- Настройки и журнал: `%APPDATA%\local-photo\`. Хранилище с фото: `D:\Cloud`.
- Установленная программа: `%LOCALAPPDATA%\Programs\local-photo\local-photo.exe` (на неё смотрит автозапуск).
- Тестовое облако для разработки: `.dev/`, http://127.0.0.1:8788 (команды в CLAUDE.md).

## Идеи

### В очереди (приняты, ещё не сделаны)

1. **Локализация интерфейса.** Сейчас все тексты зашиты по-русски в `static/*.js`, `index.html`
   и в ошибках сервера. План:
   - словари `static/i18n/ru.js`, `en.js` (дальше любые языки) и функция `t('ключ')`;
   - переключатель языка в интерфейсе, выбор запоминается; по умолчанию — язык браузера;
   - сервер отдаёт ошибки кодами (`{"error":"disk_full"}`), текст подставляет клиент;
   - Telegram-сообщения и консоль — на языке из `config.json`;
   - правило «тексты по-русски» в CLAUDE.md заменить на «тексты через словарь».
2. **Терминалы других компьютеров через облако.** Сделана первая часть (несколько сеансов
   на этом компьютере, см. сессию 2026-10-29 (4)). Осталось **уточнить у владельца**, нужно ли
   подключаться ещё и к другим компьютерам. Тогда на них ставится маленький агент, который сам
   подключается к облаку изнутри, без открытых портов. Это отдельная большая часть, со своей
   проверкой безопасности.

**Удобство**

9. **Ссылка «поделиться»** на файл/альбом без пароля, со сроком (1 день / 7 дней) и отзывом.
10. **Просмотр PDF, аудио и Markdown** прямо на сайте (сейчас всё, кроме фото, видео и текста,
    только скачивается). PDF — в изолированном окне, CSP sandbox сохраняется.
11. **Свои папки в «Файлах»** (создать, переложить). Сейчас раскладка только автоматическая по датам.
12. **Поиск по содержимому заметок и текстовых файлов** на сервере (сейчас поиск по имени
    и первой строке заметки).
13. **История версий в редакторе:** при сохранении прошлая версия уходит в корзину, а не теряется.
14. **Поиск и замена в редакторе кода** (Ctrl+F / Ctrl+H) внутри файла.
15. ✅ **Встроенный компилятор, как onecompiler** — сделано 2026-10-29 (7), `--runner on`.
    Отличия от плана: вывод потоком через NDJSON в обычном POST (не WebSocket — проще, CSP и
    CSRF как у остальных API), время работы 15 с; дерево процессов убивается `taskkill /T`
    (не job object). Дальше по желанию: несколько файлов (main + модуль), аргументы командной
    строки, история запусков, MSVC (cl.exe) для C/C++ без MSYS2.

## История сессий

Новые сверху.

### 2026-10-29 (7) — запуск кода на сайте (как onecompiler)

- `src/runner.rs`: 14 языков (Python, JS/TS через Node, C/C++ gcc/clang, C# .NET 10, Java 11+,
  Go, Rust, PHP, Ruby, Lua, PowerShell, Bash), поиск инструментов параллельно, кэш 5 мин.
  Запуск: временная папка → компиляция (до 60 с) → запуск (до 15 с, stdin, вывод до 1 МБ),
  UTF-8 для Python/Java/PowerShell, убийство дерева процессов (taskkill /T, на Unix — группа),
  «Стоп» = закрытие запроса. Не больше 2 запусков сразу. Тесты: UTF-8 на границе кусков,
  версия .NET, таблица языков, сквозной запуск (stdin, код выхода, остановка).
- Свой `which`: найдено на этом компьютере — в PATH есть лишняя `"`, из-за которой стандартный
  разбор Windows склеивает все папки после неё (не находились cargo, WindowsApps, dotnet), а
  python.exe из Microsoft Store — «псевдоним приложения», который не проверить как файл.
- `src/web.rs`: `GET /api/run/langs`, `POST /api/run` (NDJSON, `no-transform`), `runner` в
  `/api/session`, предупреждение в Telegram, как у терминала. `config.runner`, `--runner on|off`,
  строка в `--status`.
- `static/runner.js` (новый): кнопка «▶ Запустить»/«Стоп» (Ctrl+Enter) в редакторе кода,
  панель вывода (stderr красным, статус, время, код выхода, «Ввод», «Очистить», развернуть,
  граница тянется мышью), песочница «</>» → выбор языка → шаблон → запуск → «В Файлы»
  (дальше «Сохранить» перезаписывает тот же файл). Телефон: крупные кнопки, строка символов
  над клавиатурой (пары скобок с курсором внутри), редактор подгоняется под видимую часть
  экрана (visualViewport), вывод на весь экран по нажатию на заголовок. Шаблоны `RUN_TEMPLATES`.
- Проверено на `.dev` (запуск кода был временно включён там для проверки, потом выключен):
  все 5 установленных языков (Python, Java, Rust, PowerShell, Bash) — шаблоны с кириллическим
  вводом проходят; ошибка компиляции Rust, бесконечный цикл (стоп на 15 с), 1 МБ вывода,
  исключение, код выхода 7, неизвестный язык; «Стоп» в браузере убивает процесс; черновик
  сохраняется в «Файлы» и перезаписывается; запуск из открытого .py; раскладка 1280 и 375 px.
  **Не проверено:** что туннель Cloudflare пропускает вывод по ходу, а не одним куском в конце
  (запуск на настоящем облаке выключен), и строка символов на живом телефоне.
- delegate-code: шаблоны отданы бесплатной модели, ответ пришёл через ~15 мин (таймаут 90 с
  на запрос не спасает) — шаблоны написал сам. Это в «Незакрыто» скилла.
- Правка CLAUDE.md, разрешавшая агенту самому включать терминал/запуск на `.dev`, отклонена
  классификатором — правило осталось «включает только владелец».
- Выкачено на настоящее облако; запуск кода там выключен.

### 2026-10-29 (6) — резервная копия, вход с кодом, постоянный адрес

- В идеи добавлен №15: встроенный компилятор как onecompiler (план там же).
- **Резервная копия** (`src/backup.rs`): `--backup <папка>|off`, `--backup-now`. Копия в
  `<папка>\Облако (резервная копия)`, только новые/изменённые файлы (через `.part`, с mtime),
  из копии ничего не удаляется, `.local-photo` (миниатюры, корзина, загрузки) пропускается.
  Раз в сутки, первая — через 3 мин после старта; диск отключён — повтор каждый час, Telegram
  не чаще раза в сутки. Состояние в `%APPDATA%\local-photo\backup.json` и в `--status`.
  Предупреждает, если папка на том же диске; папку внутри хранилища не принимает.
- **Вход с кодом** (`src/totp.rs`, RFC 6238, зависимости `hmac`, `sha1`): `--2fa on` показывает
  QR и включает только после верного кода; `--2fa off`. Вход: после верного пароля сервер
  отвечает `need_code`, страница показывает поле кода (`autocomplete=one-time-code`).
  Неверный код = неверный пароль для блокировки, повтор кода не принимается, ±30 с.
- **Постоянный адрес**: `tunnel::Mode::Named`, `--tunnel named` (спрашивает адрес и токен,
  токен скрыт при вводе, можно вставить всю команду установки) / `--tunnel quick`. Токен —
  через `TUNNEL_TOKEN`, не в аргументах. Инструкция в README.
- Найдено и исправлено: `config::ask` не принимал ответ с BOM в начале (вставка в консоли
  Windows) — код не подходил. Теперь BOM отбрасывается.
- Новые поля config.json: `totp_secret`, `backup_dir`, `named_tunnel` (переживают `--setup`).
- Проверено: 29 тестов (6 новых, в т.ч. векторы RFC 6238), clippy чисто; вживую на `.dev`:
  копия (2 → 0 → 1 файл), отказ для папки внутри хранилища, `--status`; включение 2FA
  (3 неверных кода — не включилось; верный — включилось), вход через API (без кода / неверный /
  верный / повтор / неверный пароль) и через страницу; разбор `--tunnel named`.
  **Не проверено:** настоящий именованный туннель (нужен домен владельца).
- Выкачено на настоящее облако; все три функции там выключены, пока владелец их не включит.

### 2026-10-29 (5) — подсветка кода, поиск, удобство на телефоне и компьютере
