## Экскурс по проекту

**Что это.** Личное домашнее облако для фото и файлов. Работает на компьютере владельца,
наружу открывается бесплатным туннелем Cloudflare (`https://…trycloudflare.com`), адрес
приходит в Telegram при каждом запуске. Вход по логину и паролю.

**Из чего сделано.** Сервер на Rust (axum + tokio), интерфейс на чистом JS без сборщика.
Всё собирается в один `.exe` (~9 МБ), сайт встроен в бинарник через `rust-embed`.

**Как устроено:**

| Часть | Где | Что делает |
|---|---|---|
| Сервер | `src/main.rs`, `src/web.rs` | слушает только `127.0.0.1:8787`, все HTTP-маршруты, CSRF, загрузка по частям |
| Вход | `src/auth.rs` | сессии (на диске только хэши), блокировка подбора пароля |
| Хранилище | `src/storage.rs` | раскладка `Фото/2026/10-Октябрь/…`, даты из EXIF/MP4, защита путей |
| Туннель | `src/tunnel.rs` | скачивает и перезапускает cloudflared |
| Telegram | `src/telegram.rs`, `src/bot.rs` | присылает адрес, принимает файлы из чата |
| Терминал | `src/terminal.rs`, `static/terminal.*` | общий PTY-сеанс (PowerShell/ConPTY на Windows), xterm.js |
| Остальное | `src/trash.rs`, `notes.rs`, `zips.rs`, `thumbs.rs` | корзина 30 дней, заметки, ZIP, превью |
| Интерфейс | `static/app.js` + `editor.js`, `notes.js`, `trash.js`, `select.js` | галерея, редактор фото и текста, заметки, корзина, выбор нескольких |
| Автозапуск | `src/service.rs` | Windows Run / launchd / systemd, `--stop`, `--status` |

**На этом компьютере:**

- Исходники (рабочая копия, git → `github.com/rieS1mply/claudeweed`): `C:\Users\admin\Documents\claudeweed-main`.
  Старый клон в `C:\Users\admin\Documents\cloud\claudeweed` — не основной.
- Настройки и журнал: `%APPDATA%\local-photo\`. Хранилище с фото: `D:\Cloud`.
- Установленная программа: `%LOCALAPPDATA%\Programs\local-photo\local-photo.exe` (на неё смотрит автозапуск).
- Тестовое облако для разработки: `.dev/`, http://127.0.0.1:8788 (команды в CLAUDE.md).

## Идеи

### В очереди (приняты, ещё не сделаны)

1. **Локализация интерфейса.** Сейчас все тексты зашиты по-русски в `static/*.js`, `index.html`
   и в ошибках сервера. План:
   - словари `static/i18n/ru.js`, `en.js` (дальше любые языки) и функция `t('ключ')`;
   - переключатель языка в интерфейсе, выбор запоминается; по умолчанию — язык браузера;
   - сервер отдаёт ошибки кодами (`{"error":"disk_full"}`), текст подставляет клиент;
   - Telegram-сообщения и консоль — на языке из `config.json`;
   - правило «тексты по-русски» в CLAUDE.md заменить на «тексты через словарь».
2. **Подсветка синтаксиса в просмотре/редакторе файлов**, полная, как в IDE: `.cpp`, `.h`, `.js`,
   `.ts`, `.java`, `.py`, `.rs`, `.cs`, `.go`, `.html`, `.css`, `.json`, `.xml`, `.sql`, `.sh`, `.ps1`, `.md` и т. д.
   - Предварительный выбор: **CodeMirror 6**. Он лёгкий, хорошо работает на телефоне и умеет
     номера строк, сворачивание блоков, поиск/замену, автоотступы и парные скобки.
     Monaco (движок VS Code) тяжелее (~5 МБ) и плохо работает на телефонах.
   - Сборщика в проекте нет, поэтому готовый бандл CodeMirror кладётся в `static/`, как уже
     сделано с xterm.js. Языки грузятся только при открытии файла нужного типа.
   - CSP запрещает inline-стили, а CodeMirror вставляет свои стили. Нужен `nonce`
     (`EditorView.cspNonce`) или отдельное правило CSP для страницы редактора.
   - Тема светлая/тёмная, как у сайта.
3. **Удалённый терминал через облако с несколькими окнами.** Сейчас есть один общий сеанс.
   Нужно:
   - несколько независимых сеансов (вкладки и разбиение экрана на 2–4 панели);
   - у каждого сеанса свой id, список «открытые сеансы», создать/закрыть/переименовать,
     переподключение к любому с сохранённым экраном (как сейчас у одного);
   - ограничение числа сеансов, уведомление в Telegram о входе остаётся;
   - **уточнить у владельца:** нужно ли подключаться через облако ещё и к терминалам *других*
     компьютеров. Тогда на них ставится маленький агент, который сам подключается к облаку
     изнутри, без открытых портов. Это отдельная большая часть, со своей проверкой безопасности.
