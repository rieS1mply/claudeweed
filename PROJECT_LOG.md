## Экскурс по проекту

**Что это.** Личное домашнее облако для фото и файлов. Работает на компьютере владельца,
наружу открывается бесплатным туннелем Cloudflare (`https://…trycloudflare.com`), адрес
приходит в Telegram при каждом запуске. Вход по логину и паролю.

**Из чего сделано.** Сервер на Rust (axum + tokio), интерфейс на чистом JS без сборщика.
Всё собирается в один `.exe` (~9 МБ), сайт встроен в бинарник через `rust-embed`.

**Как устроено:**

| Часть | Где | Что делает |
|---|---|---|
| Сервер | `src/main.rs`, `src/web.rs` | слушает только `127.0.0.1:8787`, все HTTP-маршруты, CSRF, загрузка по частям |
| Вход | `src/auth.rs` | сессии (на диске только хэши), блокировка подбора пароля |
| Хранилище | `src/storage.rs` | раскладка `Фото/2026/10-Октябрь/…`, даты из EXIF/MP4, защита путей |
| Туннель | `src/tunnel.rs` | скачивает и перезапускает cloudflared |
| Telegram | `src/telegram.rs`, `src/bot.rs` | присылает адрес, принимает файлы из чата |
| Claude в Telegram | `src/agent.rs`, `src/agent_text.rs` | текст боту → Claude Code на компьютере (`--agent on`), шаги и ответ в чате, /new /stop /dir /status |
| Терминал | `src/terminal.rs`, `src/terminal_store.rs`, `static/terminal.*` | до 8 сеансов-вкладок, окно делится на 1/2/4 панели (PowerShell/ConPTY на Windows), xterm.js; сеансы и запущенный в них Claude переживают перезапуск |
| Запуск кода | `src/runner.rs`, `static/runner.js` | как онлайн-компилятор: 14 языков из установленных на компьютере, вывод по ходу, песочница «</>» |
| Остальное | `src/trash.rs`, `notes.rs`, `zips.rs`, `thumbs.rs` | корзина 30 дней, заметки, ZIP, превью |
| Папки, ссылки, поиск | `src/storage.rs` (folders), `src/shares.rs`, `src/search.rs`, `static/extras.js`, `static/share.*` | свои папки/альбомы, ссылки без пароля `/s/…`, поиск по тексту, HEIC-превью из Safari, просмотр PDF/аудио/Markdown (`markdown.js`) |
| Автозагрузка | `web.rs` `auto_upload` | `POST /api/auto-upload` по ключу `--upload-token new` (iPhone «Быстрые команды», README) |
| Язык | `static/i18n.js`, `lang-en.js`, `src/i18n.rs`, `lang_en.rs` | ru/en: сайт — по языку браузера или кнопке с глобусом, консоль и Telegram — `--lang` |
| Интерфейс | `static/app.js` + `editor.js`, `notes.js`, `trash.js`, `select.js` | галерея, поиск, редактор фото, редактор кода с подсветкой (`highlight.js`), заметки, корзина, выбор нескольких |
| Компьютер | `src/pc.rs`, `static/files.html`, `finder.js`, `finder.css` | все диски и папки, как Finder (`--files on`): виды, Quick Look, копирование/перемещение/Корзина, загрузка |
| Автозапуск | `src/service.rs` | Windows Run / launchd / systemd, `--stop`, `--status` |

**На этом компьютере:**

- Исходники (рабочая копия, git → `github.com/rieS1mply/greenclaude`): `C:\Users\admin\Documents\claudeweed-main`.
  Старый клон в `C:\Users\admin\Documents\cloud\claudeweed` — не основной.
- Настройки и журнал: `%APPDATA%\local-photo\`. Хранилище с фото: `D:\Cloud`.
- Установленная программа: `%LOCALAPPDATA%\Programs\local-photo\local-photo.exe` (на неё смотрит автозапуск).
- Тестовое облако для разработки: `.dev/`, http://127.0.0.1:8788 (команды в CLAUDE.md).

4. ✅ **Одна команда — шпаргалка по всем командам терминала** — сделано в сессии 16
   (`cmds`, кнопка «?»). Дальше по желанию: свои команды владельца в списке. Исходный план:
   `help` / `cmds` (функция в профиле PowerShell, который облако подставляет своим оболочкам,
   или кнопка «?» на странице терминала): список нужных команд с описанием по-русски —
   навигация (`cd`, `ls`/`dir`, `pwd`, `tree`), файлы (`cp`, `mv`, `rm`, `mkdir`, `cat`, `notepad`),
   поиск (`Get-ChildItem -Recurse -Filter`, `Select-String`), процессы, сеть, git, cargo,
   `local-photo --…`, `claude`; с поиском по слову (`cmds git`, `cmds удалить`) и примерами;
   на сайте — то же окном с поиском и кнопкой «вставить в терминал». Список — в одном файле,
   чтобы легко пополнять.
5. **Импорт и синхронизация фото из других облаков** (владелец, 2026-10-30: «главное — способ
   скинуть фотки с Google Фото или iCloud, или вообще как-либо их импортировать»; сделать
   максимально удобно). Что нужно знать: у Google Фото с 31.03.2025 API больше не отдаёт всю
   библиотеку (только то, что загрузило само приложение, или ручной выбор через Picker API);
   у iCloud Фото публичного API нет вовсе. Поэтому план — по удобству и надёжности:
   1. **Импорт архива Google Takeout** (основной путь для Google Фото). takeout.google.com →
      только «Google Фото» → архивы .zip/.tgz по 2–50 ГБ (можно раз в 2 месяца автоматически).
      В облаке — раздел «Импорт»: загрузить архивы с сайта (частями, с продолжением) или указать
      папку/файлы на компьютере (через «Компьютер»). Сервер сам распаковывает потоком, берёт дату
      съёмки и место из JSON-файлов рядом с фото (`photoTakenTime`, `geoData`; хитрые имена вида
      `IMG_1234.JPG.supplemental-metadata.json`, `(1)` и обрезка длинных имён), ставит дату файлу,
      раскладывает в «Фото» по месяцам, альбомы → свои папки, «-edited» версии — рядом.
      Повторы пропускает по SHA-256 (можно импортировать один архив дважды). Прогресс,
      отчёт «импортировано / повторов / без даты», возобновление после перезапуска.
   2. **iCloud Фото**: (а) iCloud для Windows (Microsoft Store) с включёнными «Фото» сам качает
      библиотеку в `Изображения\iCloud Photos` → облако следит за этой папкой (п. 3) и забирает
      новое — это и есть постоянная синхронизация без телефона; (б) архив с privacy.apple.com
      («Получить копию данных» → iCloud Фото, zip-части + CSV с датами) — импорт как Takeout;
      (в) с iPhone — уже есть автозагрузка «Быстрыми командами»; добавить на сайте кнопку
      «Загрузить всю фотоплёнку» с выбором по датам и пропуском уже загруженного, Live Photo —
      парой фото+видео.
   3. **Наблюдаемые папки**: владелец выбирает папки на компьютере (iCloud Photos, Загрузки,
      SD-карта фотоаппарата, папка Telegram Desktop) — новые фото и видео раз в несколько минут
      копируются (или переносятся — по выбору) в «Фото» по датам, без повторов.
   4. **WebDAV-сервер облака** (`/dav`, тот же логин или отдельный ключ): тогда облако видно как
      сетевой диск в Windows/macOS, а приложения PhotoSync (iPhone/Android), FolderSync,
      Резервное копирование фото Android и rclone сами синхронизируют фото в обе стороны.
   5. **Другие облака через rclone** (Google Диск, OneDrive, Dropbox, Яндекс Диск, iCloud Drive —
      не Фото): облако скачивает rclone, владелец один раз входит в нужное облако, дальше —
      забор по расписанию в выбранную папку.
   6. После больших импортов — **поиск повторов** по всей библиотеке (точные по хэшу, похожие по
      перцептивному хэшу) с удобным выбором, что оставить.
   Порядок: 1 → 3 (вместе с 2а) → 2б/2в → 4 → 5 → 6. Перед стартом спросить владельца, где
   сейчас основная часть фото (Google или iCloud) и сколько их — от этого зависит, с чего начать.

### 2026-10-30 (18) — iPhone: затемнение сверху в веб-приложении

Жалоба владельца: в веб-приложении (с экрана «Домой») верх экрана затемнён, в Safari — нет.
- Причина: `apple-mobile-web-app-status-bar-style` = `black-translucent` — iOS рисует
  полупрозрачную тёмную строку состояния поверх страницы (в iOS 26.x ещё и баг WebKit 301994:
  область статус-бара то рисуется системой, то нет).
- `index.html`, `files.html`, `terminal.html`: стиль строки состояния `black` (сплошная чёрная,
  страница начинается под ней — как в Safari). Комментарий в `style.css`.
- На iPhone не проверено. Если не прошло — удалить значок с экрана «Домой» и добавить заново
  (iOS запоминает настройки приложения при добавлении).

### 2026-10-30 (17) — «Компьютер»: файлы всего компьютера, как Finder

Просьба владельца: «делай приложение Файлы типа Finder», «даю свободу, но максимально удобно
и качественно»; плюс идея — импорт/синхронизация фото из Google Фото и iCloud (в очередь, п. 5).
- `src/pc.rs` (новый): `parse` — только абсолютные пути из обычных имён (без `..`, `\\?\`,
  сетевых путей, `файл:поток`, `NUL`/`CON`…); `Pc::check` — раскрывает ссылки и проверяет
  настоящее место: папка настроек облака и `.local-photo` закрыты полностью, Windows / Program
  Files — только чтение, родителя закрытой папки нельзя переименовать/удалить. Список (скрытые
  по атрибутам Windows), места (Избранное с учётом OneDrive, диски со свободным местом, папки
  облака), поиск по имени (все слова, ё=е, лимиты 500 / 15 с), размер папки, чтение/запись текста
  (замена через временный файл, проверка «файл изменился»), копирование и перемещение без
  перезаписи (« (2)»), перемещение между дисками = копия + удаление, удаление в Корзину Windows
  (`SHFileOperationW`, без новых зависимостей) или сразу. Всё долгое — фоновые задачи `Job` с
