## Экскурс по проекту

**Что это.** Личное домашнее облако для фото и файлов. Работает на компьютере владельца,
наружу открывается бесплатным туннелем Cloudflare (`https://…trycloudflare.com`), адрес
приходит в Telegram при каждом запуске. Вход по логину и паролю.

**Из чего сделано.** Сервер на Rust (axum + tokio), интерфейс на чистом JS без сборщика.
Всё собирается в один `.exe` (~9 МБ), сайт встроен в бинарник через `rust-embed`.

**Как устроено:**

| Часть | Где | Что делает |
|---|---|---|
| Сервер | `src/main.rs`, `src/web.rs` | слушает только `127.0.0.1:8787`, все HTTP-маршруты, CSRF, загрузка по частям |
| Вход | `src/auth.rs` | сессии (на диске только хэши), блокировка подбора пароля |
| Хранилище | `src/storage.rs` | раскладка `Фото/2026/10-Октябрь/…`, даты из EXIF/MP4, защита путей |
| Туннель | `src/tunnel.rs` | скачивает и перезапускает cloudflared |
| Telegram | `src/telegram.rs`, `src/bot.rs` | присылает адрес, принимает файлы из чата |
| Терминал | `src/terminal.rs`, `static/terminal.*` | до 8 сеансов-вкладок, окно делится на 1/2/4 панели (PowerShell/ConPTY на Windows), xterm.js |
| Остальное | `src/trash.rs`, `notes.rs`, `zips.rs`, `thumbs.rs` | корзина 30 дней, заметки, ZIP, превью |
| Интерфейс | `static/app.js` + `editor.js`, `notes.js`, `trash.js`, `select.js` | галерея, поиск, редактор фото, редактор кода с подсветкой (`highlight.js`), заметки, корзина, выбор нескольких |
| Автозапуск | `src/service.rs` | Windows Run / launchd / systemd, `--stop`, `--status` |

**На этом компьютере:**

- Исходники (рабочая копия, git → `github.com/rieS1mply/claudeweed`): `C:\Users\admin\Documents\claudeweed-main`.
  Старый клон в `C:\Users\admin\Documents\cloud\claudeweed` — не основной.
- Настройки и журнал: `%APPDATA%\local-photo\`. Хранилище с фото: `D:\Cloud`.
- Установленная программа: `%LOCALAPPDATA%\Programs\local-photo\local-photo.exe` (на неё смотрит автозапуск).
- Тестовое облако для разработки: `.dev/`, http://127.0.0.1:8788 (команды в CLAUDE.md).

## Идеи

### В очереди (приняты, ещё не сделаны)

1. **Локализация интерфейса.** Сейчас все тексты зашиты по-русски в `static/*.js`, `index.html`
   и в ошибках сервера. План:
   - словари `static/i18n/ru.js`, `en.js` (дальше любые языки) и функция `t('ключ')`;
   - переключатель языка в интерфейсе, выбор запоминается; по умолчанию — язык браузера;
   - сервер отдаёт ошибки кодами (`{"error":"disk_full"}`), текст подставляет клиент;
   - Telegram-сообщения и консоль — на языке из `config.json`;
   - правило «тексты по-русски» в CLAUDE.md заменить на «тексты через словарь».
2. **Терминалы других компьютеров через облако.** Сделана первая часть (несколько сеансов
   на этом компьютере, см. сессию 2026-10-29 (4)). Осталось **уточнить у владельца**, нужно ли
   подключаться ещё и к другим компьютерам. Тогда на них ставится маленький агент, который сам
   подключается к облаку изнутри, без открытых портов. Это отдельная большая часть, со своей
   проверкой безопасности.

### Предложения Claude на будущее (не одобрены владельцем, по важности)

Из анализа проекта 2026-10-29. Сначала то, что защищает данные и вход, потом удобство.

**Надёжность и безопасность**
1. **Резервная копия.** Всё лежит на одном диске `D:\Cloud`, копии нет. Поломка диска — и фото
   пропали. План: раз в сутки копировать новые и изменённые файлы на второй диск/внешний диск
   (`"backup_dir"` в config.json), отчёт в Telegram; предупреждать, если копия давно не делалась.
2. **Двухфакторный вход (TOTP, Google Authenticator).** Сайт открыт в интернет, а с терминалом
   пароль = полный доступ к компьютеру. Код из приложения хотя бы для терминала и новых устройств.
3. **Постоянный адрес.** Адрес trycloudflare меняется при каждом перезапуске. Варианты: именованный
   туннель Cloudflare (нужен свой домен) или Tailscale. Тогда закладка и «на экран Домой» не ломаются.
4. **Ротация журнала** `local-photo.log` (сейчас растёт бесконечно): держать 5 МБ × 3 файла.
5. **Проверка диска:** предупреждение в Telegram, когда свободного места меньше 10 ГБ (сейчас
   отказ только на загрузке при < 1 ГБ).

**Фото с iPhone**
6. **Превью HEIC.** Фото с iPhone (HEIC) хранятся, но без миниатюр и просмотра, в галерее
   заглушка. Делать превью на сервере (libheif) или сохранять копию JPEG при загрузке.
7. **Автозагрузка фотоплёнки:** готовая «Быстрая команда» iOS (Shortcuts → автоматизация),
   которая отправляет новые фото в облако по API — без ручного выбора.

**Удобство**
8. **Приложение на экран «Домой» (PWA):** manifest и иконка — открывается без панели браузера,
   как приложение. Сейчас manifest нет.
9. **Ссылка «поделиться»** на файл/альбом без пароля, со сроком (1 день / 7 дней) и отзывом.
10. **Просмотр PDF, аудио и Markdown** прямо на сайте (сейчас всё, кроме фото, видео и текста,
    только скачивается). PDF — в изолированном окне, CSP sandbox сохраняется.
11. **Свои папки в «Файлах»** (создать, переложить). Сейчас раскладка только автоматическая по датам.
12. **Поиск по содержимому заметок и текстовых файлов** на сервере (сейчас поиск по имени
    и первой строке заметки).
13. **История версий в редакторе:** при сохранении прошлая версия уходит в корзину, а не теряется.
14. **Поиск и замена в редакторе кода** (Ctrl+F / Ctrl+H) внутри файла.

### Отклонённые

- **CodeMirror 6 для подсветки кода** (2026-10-29). Без сборщика и Node его не собрать в один
  файл, а тащить сборку в проект ради одного редактора — лишнее. Взят highlight.js (один готовый
  файл) под прозрачным textarea: на телефоне остаются родная клавиатура, выделение и отмена.
  Минус: нет сворачивания блоков. Если понадобится — вернуться к CodeMirror вместе со сборкой.

## История сессий

Новые сверху.

### 2026-10-29 (5) — подсветка кода, поиск, удобство на телефоне и компьютере

- **Подсветка синтаксиса** (идея №2 из очереди): `static/highlight.js` (highlight.js 11.11.1,
  BSD-3, ядро + PowerShell + .bat, грузится только при открытии кода), `static/highlight-LICENSE.txt`.
  В `editor.js`: таблица `CODE_LANG` (~60 расширений), подсвеченный `<pre>` под прозрачным
  textarea, номера строк, панель (язык, строка/колонка, «Строка», «Перенос», A−/A+, Tab на
  телефоне), Tab/Shift+Tab по строкам, Enter с отступом, Ctrl+G, Ctrl+=/−, Alt+Z, Esc. Отступ
  определяется по файлу. Файлы > 300 КБ — без подсветки. На iPhone при открытии кода
  запрещается автозум. Настройки запоминаются (`lp-code`).
- **Поиск** по имени в Фото/Файлах и по заметкам (`/` на компьютере, Esc очищает), «Найдено N из M».
- **Телефон:** кнопка «Выбрать» больше не уезжает за край на узком экране.
- **Компьютер:** в списке файлов размер и дата отдельными колонками, подсветка строк под мышью,
  клавиши 1/2/3 — разделы, Ctrl+V загружает скриншот/файлы из буфера.
- Проверено: тесты 23/23, clippy чисто; в браузере на 1440 px и 375 px — подсветка Rust/Python,
  совпадение слоёв по высоте, отступы, Enter, отмена, поиск, ширина строки заголовка.
- Скилл delegate-code: тема подсветки отдана бесплатной модели, ответ пришёл через ~15 мин —
  тему написал сам. Скрипту нужен меньший таймаут и запуск с `-ExecutionPolicy Bypass`.
- Выкачено на настоящее облако.

### 2026-10-29 (4) — терминал: вкладки и несколько окон

Начато в чате «Cloudweed проект документация и функции», он оборвался ошибкой
`reasoning_extraction` во время проверки через браузер. Доделано в новом чате.

- `src/terminal.rs`: до 8 именованных сеансов (`MAX_SESSIONS`), id не переиспользуются,
  счётчик подключённых окон, код закрытия `4404` «сеанс закрыт». Тесты имён и лимита.
- `src/web.rs`: `GET/POST /api/terminal/sessions`, `PUT/DELETE /api/terminal/sessions/{id}`,
  WebSocket `/api/terminal?id=N` (без id — первый сеанс, для старых страниц). При
  `--terminal off` все оболочки закрываются.
- `static/terminal.*`: вкладки сеансов (+, ×, переименование двойным нажатием / долгим
  нажатием), разбиение на 1/2/4 окна (на телефоне всегда одно), раскладка запоминается,
  вкладки с других устройств подтягиваются раз в 10 с.
- Проверено: 23 теста, clippy без замечаний; API на тестовом облаке (создать, переименовать
  кириллицей, закрыть, лимит, 403 без `X-Cloud`, 404 «Сеанс не найден»). В прошлом чате
  в браузере: два окна с разными сеансами, ввод, окно подтверждения закрытия.
- Выкачено на настоящее облако (сайт отвечает локально и через trycloudflare), закоммичено и запушено.
- Новые правила в CLAUDE.md: после каждой задачи выкатывать облако; коммит и пуш самому каждые 2–3 задачи.
