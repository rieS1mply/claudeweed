## Экскурс по проекту

**Что это.** Личное домашнее облако для фото и файлов. Работает на компьютере владельца,
наружу открывается бесплатным туннелем Cloudflare (`https://…trycloudflare.com`), адрес
приходит в Telegram при каждом запуске. Вход по логину и паролю.

**Из чего сделано.** Сервер на Rust (axum + tokio), интерфейс на чистом JS без сборщика.
Всё собирается в один `.exe` (~9 МБ), сайт встроен в бинарник через `rust-embed`.

**Как устроено:**

| Часть | Где | Что делает |
|---|---|---|
| Сервер | `src/main.rs`, `src/web.rs` | слушает только `127.0.0.1:8787`, все HTTP-маршруты, CSRF, загрузка по частям |
| Вход | `src/auth.rs` | сессии (на диске только хэши), блокировка подбора пароля |
| Хранилище | `src/storage.rs` | раскладка `Фото/2026/10-Октябрь/…`, даты из EXIF/MP4, защита путей |
| Туннель | `src/tunnel.rs` | скачивает и перезапускает cloudflared |
| Telegram | `src/telegram.rs`, `src/bot.rs` | присылает адрес, принимает файлы из чата |
| Claude в Telegram | `src/agent.rs`, `src/agent_text.rs` | текст боту → Claude Code на компьютере (`--agent on`), шаги и ответ в чате, /new /stop /dir /status |
| Терминал | `src/terminal.rs`, `src/terminal_store.rs`, `static/terminal.*` | до 8 сеансов-вкладок, окно делится на 1/2/4 панели (PowerShell/ConPTY на Windows), xterm.js; сеансы и запущенный в них Claude переживают перезапуск |
| Запуск кода | `src/runner.rs`, `static/runner.js` | как онлайн-компилятор: 14 языков из установленных на компьютере, вывод по ходу, песочница «</>» |
| Остальное | `src/trash.rs`, `notes.rs`, `zips.rs`, `thumbs.rs` | корзина 30 дней, заметки, ZIP, превью |
| Папки, ссылки, поиск | `src/storage.rs` (folders), `src/shares.rs`, `src/search.rs`, `static/extras.js`, `static/share.*` | свои папки/альбомы, ссылки без пароля `/s/…`, поиск по тексту, HEIC-превью из Safari, просмотр PDF/аудио/Markdown (`markdown.js`) |
| Автозагрузка | `web.rs` `auto_upload` | `POST /api/auto-upload` по ключу `--upload-token new` (iPhone «Быстрые команды», README) |
| Язык | `static/i18n.js`, `lang-en.js`, `src/i18n.rs`, `lang_en.rs` | ru/en: сайт — по языку браузера или кнопке с глобусом, консоль и Telegram — `--lang` |
| Интерфейс | `static/app.js` + `editor.js`, `notes.js`, `trash.js`, `select.js` | галерея, поиск, редактор фото, редактор кода с подсветкой (`highlight.js`), заметки, корзина, выбор нескольких |
| Автозапуск | `src/service.rs` | Windows Run / launchd / systemd, `--stop`, `--status` |

**На этом компьютере:**

- Исходники (рабочая копия, git → `github.com/rieS1mply/claudeweed`): `C:\Users\admin\Documents\claudeweed-main`.
  Старый клон в `C:\Users\admin\Documents\cloud\claudeweed` — не основной.
- Настройки и журнал: `%APPDATA%\local-photo\`. Хранилище с фото: `D:\Cloud`.
- Установленная программа: `%LOCALAPPDATA%\Programs\local-photo\local-photo.exe` (на неё смотрит автозапуск).
- Тестовое облако для разработки: `.dev/`, http://127.0.0.1:8788 (команды в CLAUDE.md).

### Отклонённые

- **Терминалы других компьютеров через облако** (агент на других ПК, подключение к облаку изнутри)
  (2026-10-30). Владелец: «этой функции вообще не должно быть». Терминал остаётся только для
  компьютера, где стоит облако. Не предлагать снова.
- **Локализация: ошибки сервера кодами** (`{"error":"disk_full"}`, из плана локализации)
  (2026-10-30, решение Claude). Ошибки остались русским текстом, страница переводит их по
  словарю с шаблонами `{x}` (`tServer`): не пришлось переписывать ~60 ответов сервера.

- **CodeMirror 6 для подсветки кода** (2026-10-29). Без сборщика и Node его не собрать в один
  файл, а тащить сборку в проект ради одного редактора — лишнее. Взят highlight.js (один готовый
  файл) под прозрачным textarea: на телефоне остаются родная клавиатура, выделение и отмена.
  Минус: нет сворачивания блоков. Если понадобится — вернуться к CodeMirror вместе со сборкой.

### 2026-10-30 (10) — Claude в Telegram-боте

Просьба владельца: чат с агентом Claude в боте, круглосуточно. Права выбраны владельцем:
«как в терминале» — режим auto Claude Code, включает только владелец (`--agent on`).

- `src/agent.rs` (новый): текст из чата владельца → `claude -p --output-format stream-json
  --verbose --permission-mode auto --resume <id>` (запрос через stdin, переменные агента убраны,
  без окна). Под сообщением — обновляемая строка шагов раз в 4 с и «печатает…»; ответ —
  Markdown → HTML Telegram кусками по 3500 симв. (при ошибке разбора — обычным текстом).
  Очередь сообщений, `/stop` (убивает дерево процессов, очищает очередь), `/new`, `/dir`,
  `/status`; разговор и папка в `%APPDATA%\local-photo\agent.json`, переживают перезапуск;
  пропавший разговор → новый автоматически. Лимит одного задания 1 час. `--agent off` во время
  работы останавливает её. Подпись к присланному файлу уходит Claude вместе с путём к файлу.
  В системной подсказке Claude предупреждён, что `--stop` облака убьёт его самого.
- `src/agent_text.rs` (новый): `markdown_to_html` (теги всегда парные), `split_message`
  (блоки кода закрываются и открываются заново), `describe_tool` (подписи к шагам).
- `src/bot.rs`: команды, меню команд (`setMyCommands`), текст разговора не пишется в журнал.
  `src/telegram.rs`: `send_message` (с id, HTML), `edit_message`, `delete_message`, `typing`,
  `set_commands`. `config.agent`, `--agent on|off` (без Telegram — отказ), строка в `--status`.

  вернула зацикленные комментарии без кода, повтор на `nvidia/nemotron-3-ultra` упал с ошибкой.

- Проверено: 59 тестов, clippy чисто; ручной тест с настоящим Claude (`cargo test --release

### 2026-10-30 (9) — сеансы терминала переживают перезапуск, история версий, поиск в редакторе

Начато сессией Claude, запущенной в веб-терминале самого облака. Она остановила облако для
выкатки (`--stop`), умерла вместе с ним, облако осталось выключенным. Найдено по журналу,
облако поднято, её работа проверена и доделана здесь. Правило «не выкатывать из веб-терминала»
записано в CLAUDE.md.

- **Сеансы терминала после перезапуска** (`src/terminal_store.rs`, новая зависимость `sysinfo`):
  раз в 15 с и при остановке пишутся в `%APPDATA%\local-photo\terminal\` (имя, папка, последний
  вывод, запущенный в оболочке Claude Code с номером разговора). При старте оболочки
  возвращаются в те же папки со старым выводом и строкой «облако перезапущено», где был Claude —
  вводится `claude --resume <id>`. `--terminal off` стирает сохранённое. Из окружения оболочек и
  запуска кода убраны `CLAUDE_CODE_*`/`CLAUDECODE` (облако, выкаченное агентом, передавало их
  дальше, и Claude в терминале считал себя подагентом и не сохранял разговор).
- **Исправлено мной:** при каждом подключении xterm.js отвечал на старый запрос положения курсора
  из повтора экрана, и оболочка съедала первую нажатую клавишу (`claude` → `laude`). Запросы
  убраны из повтора, а запрос без подключённых окон сервер отвечает сам — восстановленная
  оболочка больше не висит до открытия страницы. Оболочка после `exit` не стартует в исчезнувшей
  папке.
- **Из идей:** №4 ротация журнала (5 МБ × 3 файла, `src/logging.rs`); №5 предупреждение в Telegram
  при < 10 ГБ свободного места (раз в сутки), свободное место в строке над списком (красное при
  < 10 ГБ); №8 PWA (`manifest.webmanifest`, иконки); №13 история версий: «Сохранить» в редакторе
  кладёт прошлый текст в корзину с пометкой версии, кнопка «История» (`GET /api/versions`);
  №14 поиск и замена в редакторе кода (Ctrl+F/Ctrl+H, регистр, регулярки с `$1`, «Все» одной
  отменой).
- Проверено: 41 тест, clippy чисто. На `.dev`: сеансы восстановились в своих папках с выводом,
  Claude перезапустился сам без открытой страницы, ввод после переподключения цел, переменные
  агента в оболочке пусты; версии сохраняются и читаются; поиск/замена через функции страницы;
  manifest и иконки отдаются без входа. **Не проверено:** `--resume` с настоящим разговором
  (проверял автор до обрыва, по его словам работало), вид поиска на экране (панель браузера была
  скрыта), PWA на телефоне.
- Выкачено на настоящее облако.

### 2026-10-29 (7) — запуск кода на сайте (как onecompiler)

- `src/runner.rs`: 14 языков (Python, JS/TS через Node, C/C++ gcc/clang, C# .NET 10, Java 11+,
  Go, Rust, PHP, Ruby, Lua, PowerShell, Bash), поиск инструментов параллельно, кэш 5 мин.
  Запуск: временная папка → компиляция (до 60 с) → запуск (до 15 с, stdin, вывод до 1 МБ),
  UTF-8 для Python/Java/PowerShell, убийство дерева процессов (taskkill /T, на Unix — группа),
  «Стоп» = закрытие запроса. Не больше 2 запусков сразу. Тесты: UTF-8 на границе кусков,
